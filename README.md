# Palette Lab

Projeto de estudo e prototipagem para geração e exploração de paletas de cores com foco em desenvolvimento web moderno.

## Visão geral

O projeto reúne uma pequena aplicação front-end para:

- criar paletas de cores a partir de valores base;
- visualizar combinações e harmonias;
- testar as cores em contexto de interface;
- exportar ou reutilizar a estrutura de paleta em código.

## Stack

- HTML
- CSS
- React
- Typescript
- Vite (estrutura de desenvolvimento local)


## Como executar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o ambiente de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Abra o endereço informado no terminal no navegador.


## Funcionalidades esperadas

- seleção de cores por input visual ou valores hexadecimais;
- geração automática de paletas complementares, análogas ou monocromáticas;
- preview em cards, botões e textos;
- geração de código de uso rápido para CSS/JS;
- interface leve e responsiva.

## Observações

Este é um projeto de laboratório/estudo, então o foco está em experimentação, organização visual e simplicidade de uso. A estrutura foi pensada para facilitar ajustes rápidos e futuras extensões.
